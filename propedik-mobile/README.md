# PROPEDIK — Мобильное приложение Android (Propedik Mobile)

Полноценное мобильное Android-приложение клинического тренажёра PROPEDIK на базе Capacitor и нативного Android Gradle.

## Особенности мобильной сборки
- **Полная автономность (Offline-first)**: все рентгенограммы, аудиозаписи дыхательных шумов и база тестов встроены в APK и работают без доступа к интернету.
- **Мобильная эргономика**: нижний таббар (Bottom Navigation Bar), оптимизация под вырезы экранов (Safe Area), компактные 1-колоночные сетки тестов.
- **Адаптивная иконка (Adaptive Launcher Icon)**: фирменный медицинский стетофонендоскоп на тёмно-бирюзовом фоне.
- **Готовый APK**: скомпилированный установочный файл находится в корне мобильного модуля: `PROPEDIK.apk`.

## Инструкция по сборке
1. Подготовка и синхронизация веб-ассетов из `../propedik-web`:
   ```bash
   node build-mobile.js
   npx @capacitor/cli sync
   ```
2. Компиляция установочного APK через Gradle:
   ```bash
   cd android
   .\gradlew.bat assembleDebug
   ```
   Собранный файл будет доступен в: `android/app/build/outputs/apk/debug/app-debug.apk`.
