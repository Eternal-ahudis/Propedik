Интерактивная аускультация легких

Интерактивная цифровая модель топографических точек выслушивания дыхательных шумов грудной клетки с аудио-сопровождением и клинической дифференциацией.

Обзорная рентгенограмма легких (прямая проекция) — Передняя группа точек
Проекция:
V1 Правая верхушка (надключичная область)
V2 Левая верхушка (надключичная область)
V3 Подключичная область справа (I м/р по среднеключичной линии)
V4 Подключичная область слева (I м/р по среднеключичной линии)
V5 II межреберье справа по среднеключичной линии
V6 II межреберье слева по среднеключичной линии
V7 III межреберье справа по среднеключичной линии
V8 III межреберье слева по среднеключичной линии
B1 Область гортани (перстневидный и щитовидный хрящи)
B2 Шейный отдел трахеи (над яремной вырезкой грудины)
B3 Рукоятка грудины (бифуркация трахеи спереди, Th3–Th4)
V1 Надлопаточная область справа (fossa supraspinata, над остью лопатки)
V2 Надлопаточная область слева (fossa supraspinata, над остью лопатки)
V3 Межлопаточное пространство справа (верхний отдел, уровень Th3–Th4)
V4 Межлопаточное пространство слева (верхний отдел, уровень Th3–Th4)
V5 Межлопаточное пространство справа (нижний отдел, углы лопаток Th6–Th7)
V6 Межлопаточное пространство слева (нижний отдел, углы лопаток Th6–Th7)
V7 Подлопаточная область справа, VII межреберье по лопаточной линии
V8 Подлопаточная область слева, VII межреберье по лопаточной линии
V9 Подлопаточная область справа, VIII межреберье по лопаточной линии
V10 Подлопаточная область слева, VIII межреберье по лопаточной линии
V11 Базальный отдел справа, IX межреберье по лопаточной линии
V12 Базальный отдел слева, IX межреберье по лопаточной линии
B1 Остистый отросток VII шейного позвонка (C7, vertebra prominens)
B2 Межлопаточное пространство по срединной линии (Th3–Th4, бифуркация трахеи сзади)
L1 IV межреберье по среднеподмышечной линии (linea axillaris media)
L2 V межреберье по среднеподмышечной линии (linea axillaris media)
L3 VI межреберье по среднеподмышечной линии (linea axillaris media)
Везикулярное дыхание: 8 симметричных точек спереди (верхушки, ключицы, I–III м/р по среднеключичной линии)
Бронхиальное дыхание: 3 точки по срединной линии (гортань, трахея, рукоятка грудины)
Выбор типа дыхания для выслушивания
ГРУППА 1: ВЕЗИКУЛЯРНОЕ ДЫХАНИЕ (ЛЕГОЧНЫЕ ПОЛЯ)
ГРУППА 2: БРОНХИАЛЬНОЕ ДЫХАНИЕ (КРУПНЫЕ ПУТИ)
Везикулярное дыхание (норма)
Вдох (Inspirium) 00:00
Громкость звука:
Клиническая характеристика: Везикулярное дыхание
Топография точек: Симметрично над всей поверхностью легких (точки V1–V10).
Акустическая формула: Слышен весь вдох и только начальная 1/3 выдоха (соотношение 3 : 1). Мягкий шум, напоминающий звук «ф».
Механизм возникновения: Колебания эластичных альвеолярных стенок при их быстром растяжении поступающим воздухом во время вдоха.
Физиологические условия: Норма у здоровых взрослых людей при спокойном дыхании.
