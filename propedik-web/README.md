# PROPEDIK — Веб-платформа (Propedik Web)

Интерактивный клинический тренажёр по пропедевтике внутренних болезней (пульмонология): аускультация лёгких, синдромология, семиотика, рентгенография органов грудной клетки и дифференциальная диагностика.

## Структура дистрибутива
- `index.html` — главное SPA-приложение (4 раздела: Интерактивная аускультация, Патологии и синдромы, Тестирование знаний, О проекте).
- `css/style.css` — фирменный адаптивный дизайн (десктоп, планшеты, смартфоны).
- `js/app.js` — логика интерактивных точек, аускультативного плеера, адаптивного интервального повторения Лейтнера и тестов.
- `js/data.js` — структурированная клиническая база данных синдромов, акустических паттернов и тестовых вопросов.
- `audio/` — 14 физических аудиозаписей физиологического и патологического дыхания (везикулярное, бронхиальное, крепитация, сухие и влажные хрипы, шум трения плевры).
- `image/` — рентгенограммы нормальной анатомии и патологических синдромов.
- `icons/` — фирменные иконки со стетофонендоскопом.
- `docs/` — методические пособия кафедры пропедевтики внутренних болезней (PDF).
