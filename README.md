# Propedik — Интерактивная платформа по пульмонологии

Образовательный веб-тренажер по физикальной диагностике дыхательной системы.

## Онлайн-версия
- **GitHub Pages**: https://eternal-ahudis.github.io/Propedik/

## Возможности
1. **Интерактивная аускультация**: 3 проекции (передняя, задняя, боковая), топографические точки выслушивания, Web Audio синтезатор и аудиозаписи.
2. **Атлас синдромов**: 11 ключевых легочных синдромов с рентгенологическими данными и физикальной семиотикой.
3. **Тестирование**: слепое распознавание дыхательных шумов на слух и теоретический опросник.

## Стек технологий
- HTML5, CSS3, JavaScript (Vanilla ES6)
- Web Audio API, Canvas 2D
